## v0.1.3 · 2026-08-20 · ff69369

### 时间逻辑定稿 + 启动自检框架

- **外部 RTC 芯片（PCF85063）= 唯一时间权威**：开机自检读芯片，ACK + OS=0（晶振在走）→ 无条件采纳为系统时钟；去掉 v0.1.2 的编译时间比较——OS=0 保证时间连续，「有效但过期」不存在
- 芯片失效（无芯片 / 停振 OS=1）→ 编译时间兜底起步 + 写回芯片重新走时（写秒自动清 OS）
- 自检输出 `[自检·时间] ✓/⚠` 格式就位（启动自检框架首项，SD 卡/屏幕/电池自检后续扩展）

## v0.1.2 · 2026-08-20 · 14708bb

### 修复：录音文件日期永远停在编译日（v0.1.1 佩戴发现）

- **根因**：`TimeSync::begin()` 无条件 `setRtcFromCompile()` → `settimeofday(编译时刻)`，每次开机把 `rtcBegin()` 刚设好的有效芯片时间砸掉。屏幕直读芯片所以一直正确，极具迷惑性
- **取证**：SD 卡 `.logs` 同次开机时间戳倒跳（芯片 02:05:17 → 编译 20:55:25）；两次开机（相隔 3h）后续戳完全相同 = `__TIME__` 常数；芯片两次读数精确走 3h07m → 芯片健康，被砸的只是系统时间
- 修复：删 `setRtcFromCompile`；`sync()` 不再自设时间，经回调交付
- `pod::rtcSet()` 成为统一校时入口：settimeofday + 写芯片一次完成；入口守卫拒绝 <2020-01-01 异常值
- 状态：被 v0.1.3 取代，未单独烧录

## v0.1.1 · 2026-08-18 · 060afdc

### 修复：录音中长按 BOOT 静音后绿灯常亮（佩戴实测发现）

- 根因：静音路径先置 `muted=true` 再 `splitSegment()` 收尾，收尾回调灭灯条件 `mode==NORMAL && !muted` 被跳过，MUTED 态无人驱动绿灯（§7 规定 MUTED=灭）
- 顺带：静音切换日志从仅串口改为 `pod::log::event` 双写（串口+SD 卡）
- 状态：✅ 已实测验收（2026-08-20）

## v0.1.0 · 2026-08-17 · ab7f7fe（当日修正 8e7adbd / 1ed6eaf / b58d0a7）

### 首个正式版：全功能

- **录音链路**：VAD 自动录音（ES8311 模拟麦 I2S + SD_MMC IDF 挂载 20MHz 1-bit），预滚 2s / 最长段 300s / BOOT 短按切段续录（保留预滚衔接）
- **协议落卡**：`.echo-pod` 标志文件（serial = ES3- + efuse MAC 后 4 字节）+ `echo-pod/日期/HH-MM-SS.wav` 命名（App 按卷 + 标志识别，已实测）
- **交互全量**：七状态墨水屏（局部刷新 ~600ms）/ 按键矩阵（短按切段·刷新，长按 3s 静音·关机）/ 绿灯策略 / 低电 8% → 60s 强制关机 / PWR 软闩锁真关机
- 当日修正①：录音绿灯漏驱动（回调补 setLed）+ 今日段数跨重启恢复（扫卡续算）+ VAD 收紧（high 0.60→0.68，attack 0.92→0.94，佩戴偏灵敏）
- 当日修正②：SD 运行日志 `echo-pod/.logs/`（串口+卡双写、事件级 fflush、保留 7 天，协议 v1.1）
- 当日修正③：RTC 时区换算显式化（mktime→days_from_civil + 固定东八区，修文件名从 0 点）+ `SETTIME:` 串口校时联动写芯片
- 已根治的坑（留档）：arduino SD_MMC 默认 40MHz 边缘态（换 IDF 挂载）；1.54G 四色驱动误用于黑白屏（换官方 B/W BSP verbatim）；I2C SDA 卡低 9 时钟恢复
